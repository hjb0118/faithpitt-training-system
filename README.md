# 凡碧诗培训管理系统

四阶段闭环培训管理平台：申请 → 审批 → 总结 → 30天回访 → 90天评估

## 访问地址

- 本地：http://localhost:3000
- 局域网：http://192.168.0.141:3000
- 外网：http://47.96.158.178:3000

## 技术栈

- 后端：Node.js
- 前端：HTML + CSS + JavaScript
- 数据存储：JSON 文件
- 部署：阿里云 + pm2

## 功能特性

- ✅ 培训申请与审批流程
- ✅ 学习总结提交
- ✅ 30天回访与90天评估
- ✅ 企业微信通知
- ✅ AI辅助回访备注
- ✅ 数据看板与报表导出
- ✅ 移动端响应式设计

## 部署方式

```bash
# 本地运行
node server.js

# 一键部署（Git + 云服务器）
python deploy_all.py
# 或双击 运行部署.bat
```

## 自动部署

Push 到 `main` 分支后，GitHub Actions 自动同步到云服务器并重启服务。
